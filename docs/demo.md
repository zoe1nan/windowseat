# 5 分钟演示脚本

> 目标：在真实 Edge 里走完「选文 → 提问 → 流式回答」。全程本机 loopback。

## 准备

1. DSH 桌面端已启动，bridge 在跑：

   ```bash
   curl -s http://127.0.0.1:34281/windowseat/health
   # {"ok":true,"name":"windowseat-bridge",...}
   ```

2. Edge 已加载扩展：`edge://extensions` → 开发人员模式 → 加载解压缩的扩展 → `<仓库路径>\extension`。
3. 随便打开一个 `http(s)` 网页（技术博客、文档、新闻都行）。

## 演示

1. **划词提问**：在页面选中一段文字 → 浮条出现 → 点「解释」→ 侧边栏自动带入选中内容，回答流式出现。
2. **直接提问**：面板输入「用一句话解释这段话」，Enter 发送。
3. **停止/重试**：长回答时点「停止」；再点「重试」。
4. **多轮**：同一会话继续追问「那它和上下文的关系呢？」。
5. **历史会话**：顶栏时钟图标打开历史抽屉 → 切回上一段对话继续聊。
6. **@ 本地文件**：输入框输入 `@` + 文件名关键词 → 选中文件 → 提问，回答会引用文件内容。
7. **截图提问**：点输入框左下「截图」→ 缩略图出现 → 问「这张截图里的标题是什么」。
8. **协同小队**：说「创建一个叫 reviewer 的队员，建个共享任务派给它」→ 输入框上方小队条显示成员与任务。
9. **断线恢复**：关掉 DSH → 面板显示「未连接」；重启 DSH → 点「重新检测」恢复。

## 验收对照

| 项 | 期望 |
|---|---|
| 浮条 | 页面划词出现 5 个动作，不遮字、不影响原页面样式 |
| 上下文 | 面板 chips 显示页面/选中，提问自动带上 |
| 流式 | 文字逐段出现，非一次性整段 |
| 停止 | 2 秒内停止并提示，可继续提问 |
| 断线 | DSH 关闭时明确引导，不白屏 |
| 布局 | 320/400/560px 不重叠不裁切；微软雅黑 / Segoe UI |
